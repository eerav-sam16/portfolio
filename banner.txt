import { useEffect, useRef } from 'react'

export default function useReveal(options = {}) {
  const ref = useRef(null)

  useEffect(() => {
    const el = ref.current
    if (!el) return
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          el.classList.add('visible')
          observer.unobserve(el)
        }
      },
      { threshold: 0.08, rootMargin: '0px 0px -50px 0px', ...options }
    )
    observer.observe(el)
    return () => observer.disconnect()
  }, [])

  return ref
}

also in my resume and portfolio website, should i also add my leetcode profile?
Short answer: No, skip it.

Here's why for each:

Resume — Recruiters at product companies care about what you've built in production, not competitive programming. You already have strong impact metrics (10M+ users, <200ms, 99.95% uptime) — a LeetCode link adds nothing next to that.

Portfolio — Same reasoning. Your portfolio shows real systems you've designed and owned end to end. LeetCode profiles signal practice, not production experience. It can actually undersell you.

The one exception — if you're applying to FAANG/top product companies that are heavy on DSA rounds (Google, Meta, Amazon), some people add it. But even then it only makes sense if your solve count and rating are strong (700+ solves, high contest rating). If that's the case for you, it's worth considering for those specific applications only.
